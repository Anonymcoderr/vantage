Analyse your own contract — needs the tool itself
What this is, what to pick, and how to read the result

What it does

Choose a test (a small concurrent program) and a memory model (a .cat file of relations and axioms). The tool enumerates every execution the program allows, checks each against the model, and draws one.

What a test looks like

arch = "AArch64"
name = "MP+po+addr"
symbolic = ["x", "y"]            # fresh memory locations

[thread.0]
init = { X1 = "x", X3 = "y" }     # seed registers
code = """
    MOV W0,#1
    STR W0,[X1]                  # write the data
    MOV W2,#1
    STR W2,[X3]                  # then set the flag
"""

[final]
assertion = "1:X0 = 1 & 1:X2 = 0"    # the outcome being asked about

Names encode the shape then the ordering used in each thread: MP+po+addr is message passing where thread 0 relies on program order and thread 1 on an address dependency. +dmb.sy is a full barrier, +ctrl a control dependency, +fence.rw.rw the RISC-V fence.

Which model to pick

Group 1 holds the architecture models. Pick one of those for ordinary memory-model work. The leakage groups pose a research question and are not alternatives to each other: a question is posed by a model, which is why there are so many. Groups 3 and 4 come in families where two files differ by one line, and running both is the experiment.

Do not pick an lcm- model to check ordinary ordering, or a bare architecture model to ask a leakage question.

What comes back

allowed (n of m) means the model permits the outcome; at least one execution satisfies it. forbidden (0 of m) means none does. m counts results, not candidates: for a forbidden cell it equals the candidate count; for an allowed cell it counts satisfying models and is not reproducible between runs.

Caution. A forbidden only means something if the program has executions at all, and for leakage cells only if the relation could have been populated. Both have produced false results here.

Speculation depth

0 means no speculative execution. Spectre-style tests need 2 or more: at depth 0 there are no transient events, so nothing is detected and the cell reports a clean negative that measures nothing.

What this selection means

Result
Choose a test and press Run. Spectre tests need a speculation depth of 2 or more. At depth 0 there are no speculative events and nothing is detected.
